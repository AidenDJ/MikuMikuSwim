# 游戏内界面中英双语（0.1.2）

界面语言默认**跟随游戏语言**，读取的是游戏自己的 `Language.main.GetCurrentLanguage()`，
而且是每次取值时现读，不缓存：在游戏选项里换语言，模组界面下一帧就跟着换，不需要重启。
只有游戏 `Language` 对象还不存在、或当前语言为空时，才退回操作系统语言。

配置项 `[Interface] UiLanguage` 仍可取 `Auto` / `Chinese` / `English`，默认 `Auto`；
`Chinese` / `English` 强制指定，压过游戏语言。手改配置文件要重启才生效。

## 实现

- 新增 `UiText`：`T("中文", "English")` 在所有自绘文案处并列写出两个字符串，漏翻是源码里
  看得见的空缺，不会变成运行时的静默回退。
- 语言判定不设缓存：`UiText.English` 每次取值都重新判断（显式模式直接返回，`Auto` 现读
  游戏语言），所以游戏语言变化能立刻反映到控制台和 PDA 页面。
- MMS 控制台（F2）新增「界面语言」一行，三个按钮 Auto / 中文 / English，点下即改并写入
  配置。控制台是 IMGUI、每帧重绘，文字立刻跟着变。
- PDA 模型页的每个标签在构建时就写进 `Text` 组件，所以语言变化后要重建页面：记下建页时
  的语言 `_uiEnglish`，在 `Open()` 和 `HostLateUpdate()` 里比对，不一致就销毁子节点重跑
  `BuildUi()`。预览相机和 RenderTexture 保留，新图沿用同一张贴图。
- 英文文案全部限制在可打印 ASCII，动态字体预热补了整段字符集（原先只预热汉字）。
- 英文标签比四字中文长：英文下滑条标签列由 124 px 加宽到 156 px，滑块起点同步右移。

## 验证

编译通过（只剩 `_itemGrip*` 原有的未使用字段警告）。部署后在中文语言环境下启动游戏：

- 日志 `Loading [MMS 0.1.2]`、`UI language: Chinese.`、`PDA page font prewarmed`，无异常

**未验证**：PDA 页面重建、控制台按钮点击、游戏内切换语言后的实际显示。这几条都要读档
进游戏并操作界面，且按要求不做截图判断。改动集中在 `UiText`、`MmsConsole`、
`PdaModelTab` 的建页逻辑，模型、物理和骨骼逻辑没有改动。
