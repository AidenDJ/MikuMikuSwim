# YYB 马尾恢复（0.1.18）

0.1.17 的自动识别把 YYB 原本由网格生成马尾处理的辅助骨骼提升为原生物理骨骼，改变了蒙皮绑定，导致马尾持续卷曲。

对模型元数据中标识 YYB 且已有可识别头发骨骼的模型，恢复原有头发绑定：保留原先识别出的头发链，不让新增的推断头发链接管马尾。默认 YYB、10th、NT、运动衣、赛车等变体沿用原有生成马尾/既有原生链；衣服和其他模型的自动识别继续运行。没有现有头发识别依据的模型仍走自动推断。

30 个安装模型的转换回归通过；8 个 YYB 文件的原生头发识别数逐个与 0.1.16 的基线一致：默认、10th、Re:Mikus、赛车、运动衣为 18，NT 与对应泳装为 94。详细结果见 `build/yyb-hair-018/verification.json`。

此检查验证绑定数据恢复，未启动游戏验证最终摆动观感。构建只有原有四项未使用字段警告；模型与材质未修改。
