# 自动识别头发、衣物和饰带（0.1.17）

新 PMX 放入 Models 后，在首次导入时自动分析，不需要为每个模型维护名单或先修改骨骼名。识别结果缓存到模型数据，运行时使用已有头发、裙摆、衣服、饰物开关。

识别依据由强到弱组合使用：

1. 骨骼的中英文名称和父子链；
2. 材质中英文名、贴图文件名，以及材质覆盖的顶点对各骨骼的真实权重；
3. PMX 刚体关联的骨骼、动态/跟随模式，以及是否存在关节连接；
4. 动态链挂在头、腰、躯干或手臂的位置、链长和相对模型高度的范围。

骨骼命名不完整时，可以根据其它证据恢复类型，并沿链补充未翻译的中间节点。识别出的头发同时用于头部网格归类和第一人称头发拆分，不再要求材质也必须叫 Hair。分析只在模型导入阶段执行；没有加入每帧的全模型扫描。

身体驱动骨骼、IK、面部、胸臀及固定锚点排除；短贴身袖口沿用原处理。证据不足的部位保持静态，不强行加入物理。仅靠网格和匿名材质无法保证完全区分头发、布料和皮肤；没有可靠信息的任意模型并不保证 100% 自动识别。

PMX 读取扩展到刚体和关节，跳过形态键和显示帧；支持不同索引宽度及常见 2.0/2.1 记录。可选尾部缺失、截断或非法时，保留几何与骨骼导入并记录原因，不让新增的元数据读取阻止模型加载。字段布局参考 [PMX 2.1 格式说明](https://github.com/dskjal/OpenMMD/blob/main/docs/specification/pmx2.1-specification.md)。

## 验证与边界

- 30 个实际安装的模型，全部成功读取物理元数据并完成转换。
- 每个模型进行了正常转换、隐藏已识别部位的骨骼/刚体名称、再隐藏材质和贴图名称三种运行，共 90 次完成，无导入失败。匿名测试记录实际恢复率，并不把“成功转换”等同于“所有部位都识别正确”。完整结果见 `build/auto-parts-017/verification.json`。
- 隐藏骨骼/刚体名称后，HCMiku 恢复头发 24/24、衣物 32/32；安克雷奇头发 139/139；赛车初音长发 132/132。部分模型的匿名部位只能恢复一部分，例如狮的头发 79/153。
- 独立断言覆盖仅凭贴图与权重识别匿名头发、仅凭动态链识别匿名头发/裙摆、身体驱动排除，以及无证据不添加物理。
- 可选元数据完全缺失、截断、非法计数三种降级检查通过。
- Sour 右袖口、HCMiku 双尾，以及 HCMiku / Sour White / YYB 10th 的旧颈口补面检查通过。

构建仅有原有四个未使用字段警告。未启动或操作游戏，实际碰撞、摆动和遮挡仍需要用户检查。未改模型源文件与材质。
