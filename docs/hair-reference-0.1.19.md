# 长发统一使用 YYB 参考方案（0.1.19）

YYB 当前稳定的处理路径保留。其它模型中能可靠分离的长发，改为同一套整束八段模拟与权重过渡；短发、刘海、衣服和饰品继续使用各自原有的分类与约束。

导入后根据头发材质、权重、连通壳层及发根位置，将邻近的薄片归成同一束。单马尾不会因为跨越身体中心线被切成左右两半；分离的双马尾保留独立发根。连接在长发上的头皮区域保持固定。完成分组后，长发顶点移交统一模拟，不再叠加对应的原生细骨链；每束使用与 YYB 相同的八段形态、弯曲和防扭转处理。

采用不超过 16 束的可靠分组；不足以形成长发束的几何保留原处理。改动只在模型构建时运行分组和重绑，不新增逐帧模型扫描。原模型网格和贴图文件不修改。
