# 0.1.6 性能整理

在用户验证通过的 0.1.5 通用持物 IK 上，保持握点、臂长、肘向限制和求解次数，减少重复工作。

- 模型构建时缓存手臂与躯干骨骼引用，重建模型时重新校准、替换缓存。
- 物品组件与武器分类只在换物品时读取；不存在工具组件的鱼类也会缓存查找结果。左右手目标、换电池期间目标变化仍逐帧读取。
- 空手且收起过渡结束时，跳过 IK 的躯干姿势读取；PDA、剧情、载具和吸血虫状态仍优先接管。
- 掌心固定旋转偏移与全身重定向中的绑定逆旋转只计算一次，实时姿态继续逐帧计算。
- 肘向已在允许范围内时直接返回，省去不必要的旋转插值。
- 待机动画抑制使用缓存的 Animator 引用和参数 ID；原始输入日志只在详细诊断开启时构造。
- `HoldIkLog` 默认关闭，需要排查持握时可以重新打开。旧配置会保留原值。

编译结果检查确认：`SolveAdaptiveHand` 中的骨骼查找调用由 7 处降为 0，字符串拼接由 7 处降为 0，组件查找由 2 处降为 0。这是静态调用位置数量，实际执行次数取决于单/双手和动作状态；更新阶段的组件查找只在缓存失效时执行。

构建通过。独立数学等价检查覆盖 10,000 组输入：肘向快速路径的最大向量差约 `5.8e-15`；单精度旋转乘积改为缓存结合顺序后的最大分量差约 `1.2e-7`。这些检查不能代替游戏内动作和蒙皮验证，也不是 FPS 测量。

按用户要求，部署后由用户启动和操作游戏。没有声明具体帧率提升比例。

## 构建

```powershell
.\tools\build_plugin.ps1 -GamePath "D:\Program Files\Steam\steamapps\common\Subnautica" -MonoPath "D:\Program Files\Unity 2019.4.36f1c1\Editor\Data\MonoBleedingEdge"
```

需要游戏的 Managed 程序集、BepInEx 5.4 及 Unity 2019.4 的 Mono 编译器。输出为 `build/adaptive-ik/PlayerModelReplacer.dll`。关闭游戏后替换插件目录中的 DLL。仓库不包含模型、贴图或游戏程序集。
