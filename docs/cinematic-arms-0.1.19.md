# 0.1.19 过场手臂显隐修复

过场动画中，摄像机触及脖子或胸腔的防穿模区域时，旧逻辑会将整个身体渲染器设为仅投影。手臂和袖子属于同一个网格，因此也会短暂消失。

此修复保留原来的身体内部保护，在保护生效期间补绘双臂及其袖子。通过标准化肩、肘、手骨骼及子骨骼的蒙皮权重识别区域，不依赖具体模型的材质名称。普通状态关闭补绘，避免透明袖子重复叠加。原材质、发光和阴影继续使用；PDA 隐藏的材质同步排除。

模型构建时生成辅助网格，常规每帧只更新显隐开关；用户调整部件显示后，下一次保护生效时刷新索引。切换模型时释放辅助网格。保留 0.1.19 的头发行为，不引入 0.1.20 或 0.1.21 的头发修正。

验证：完整插件编译成功。tools/test_cinematic_arms.ps1 通过合成的骨骼继承、循环保护、肩部混合权重、隐藏材质检查；29 个安装模型均保留左右手臂并排除躯干区域。未启动游戏，实际过场显隐和视觉效果由用户验证。
