# 新模型头发与衣服兼容修复（0.1.16）

新加入的碧蓝航线模型使用中文骨骼名、仅在英文名标注用途的骨骼，以及插在链条中的未翻译辅助骨骼。此前这些骨骼在导入时被丢弃并合并到身体，造成头发无物理、长袖或飘带跟随错误。

修复覆盖导入与运行时两端：

- 识别后发、发絮、发毛、编号发链、马尾，以及飘带、项圈带、长袖等名称；读取 PMX 英文骨骼名作为补充。
- 未翻译的中间节点沿父链继承分类。身体驱动骨骼、IK、固定节点和已有袖口辅助映射保留排除规则。
- 骨骼数据保存分类，皮肤权重保留、头部网格划分和物理链构建使用同一分类，不依靠修改骨骼名称。
- 不同类型之间分开建立链条，避免把衣摆误当头发，或跨类型串进同一条物理链。
- 短贴身袖口仍走原有处理；连续至少四段的通用袖链才按悬垂布料识别。

实际安装目录的六个新模型已验证：狮、拉菲 II、不挠、信浓、安克雷奇、伴尔维。以狮为例，保留头发骨骼从 1 根变为 153 根，可模拟长发链从 0 条变为 6 条。兼容规则不依赖模型文件名。

验证：构建成功，仅有此前存在的四个未使用字段警告；全部 30 个已安装 PMX 转换通过，检查皮肤权重归一化、分类骨骼保留和新模型长发链有效性。另含中英文补充、未翻译链节点、固定节点排除、发射器误匹配排除及短袖口等分类断言。HCMiku 双尾、Sour 右袖口回归通过。原先支持的 HCMiku、Sour White、YYB 10th 三个颈口补面检查通过。

扩大颈口检查到全部模型时，YYB NT 报告不存在闭合颈部边界；用仓库 0.1.15 原代码重测也同样失败，记录在 `build/compat-016/baseline-neck-nt.log`，属于原有颈口检测限制。本次未改颈口生成器。
