# 0.1.13：第一人称头部与过场头发

修正 0.1.12 的过场保护策略：不再把近距离过场的整个头发渲染器设为仅投影；过场中保留头发可见性和现有物理跟随。穿入头部的保护仍作用于头部网格，保留其阴影，不通过隐藏双马尾解决。

普通第一人称现在也按摄像机的绝对朝向驱动头部，包含俯仰和侧倾；不受第三人称的待机淡出影响。使用替换目标朝向的方式，避免在源动画已有俯仰时再叠加一次。视角切换时按镜头混合权重过渡，远距离过场镜头保留源动画。

头部隐藏判断检查摄像机位置及近裁剪面中心，并按近裁剪面角点范围扩张头部边界。通过模型宿主的 Camera.onPreCull 回调，在主摄像机绘制前再次检查，覆盖 LateUpdate 后的镜头动画；忽略 PDA 预览等其他摄像机。回调随宿主启用、停用成对注册、注销。

验证：以安装游戏的程序集构建通过，四个原有未使用字段警告。头部绑定坐标与侧倾映射的离线检查通过。未启动或操作游戏，头发外观、第一人称各角度和具体过场的穿模仍待用户在游戏内验证。
