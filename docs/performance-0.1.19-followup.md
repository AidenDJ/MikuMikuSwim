# 0.1.19 性能补丁

依据当前代码和游戏日志排查，当前模型有 43 条导入次级运动链、179 个链骨骼。碰撞循环对每个采样点、每个身体碰撞体和每轮约束重复访问 Unity Transform。同一轮布料求解期间，身体骨骼保持不变；这些跨引擎调用可以集中读取。

本次改变：

- 每帧收集碰撞体时缓存身体矩阵、世界位置、逆旋转及缩放，所有碰撞采样复用。腿部运动扩张继续每帧更新，所有头发/衣物求解次数保持不变。
- 每条链开始碰撞前缓存蒙皮外壳偏移，复用于所有轮次和中间采样点；缓存数组复用，无每帧新增数组。
- 过场显隐开关仅在状态改变时写入，避免 LateUpdate 和摄像机剔除前重复设置渲染状态。

检查结果：完整插件编译成功。10,000 组随机旋转、正负/非均匀缩放、平移及连续姿态的坐标检查通过，最大误差 0.00003924 米。

实际编译 IL 检查：PushSampleOutOfBody 的 Transform 调用位置 3→2，PushOutOfSlices 5→1，ShellOffset 1→0。剩余调用为采样位于碰撞体正中心时的链根回退；身体骨骼读取移至每帧缓存。此数字是静态调用位置数量，不是 FPS 提升比例。

PDA 已有静态预览按需渲染及界面部件复用，本次未发现需要改成持续重绘的理由，保留现有行为。日志记录的场景 GC/资源回收约 300 毫秒属于游戏加载流程；日志不足以断言它由此模组触发，未更改游戏全局 GC 或画质设置。

仍以 0.1.19 为模型功能基线，保持其头发方案、IK、透明及发光材质。没有启动游戏，也没有实时帧时间采样；实际卡顿改善需在同一场景和模型下由用户验证。后续如仍卡顿，需要区分持续低帧、转视角掉帧、PDA 切模型停顿和场景加载停顿。
