本模组不附带任何模型。把 MMD 模型放进这个文件夹，每个模型建一个子文件夹：

  Models\YYB Miku\
      model.pmx          <- 模型本体（只有一个 pmx 时文件名随意）
      tex\...            <- 贴图，按 PMX 里写的相对路径查找；找不到时再按文件名找

一个文件夹里可以放多个 pmx（比如同一个角色的两个配色）：

  Models\sour暄\
      Black.pmx
      White.pmx

它们会作为两个独立条目出现在模型页里，名字是「sour暄 · Black」「sour暄 · White」，
可以分别预览、分别应用，隐藏/发光设置也各存一份。有 model.pmx 时默认选它，
否则按文件名排序取第一个。

第一次启动游戏（以及之后每次启动，直到勾选“不再显示”）会弹出“使用须知”窗口：
使用任何模型前，请先阅读并遵守该模型自带的 README 中的使用条款
（署名要求、可否修改、可否商用、禁止事项等）。勾选“不再显示”再点“我同意”，
以后启动就直接进入游戏；不勾选则每次启动都会再问一次；点“我拒绝”会直接退出游戏。
没有放模型时模组不会替换任何东西，游戏照常是原版主角。

进游戏后按 V 直接打开 PDA 的「模型」页（也可以正常打开 PDA，点顶部标签行最后的
MMS logo 图标）。左边点名字会先在右上预览这个模型的 T-pose（不换装），
确认后点“应用模型”才真正换上身；预览里左键拖动旋转、滚轮缩放、右键拖动平移。右下可以：
  - 按材质勾选：左边勾上 = 隐藏该部位（世界里的模型和预览同时消失），
    右边的“发光”勾上 = 该材质按贴图本身的颜色发光；
    “全部显示”一键恢复隐藏；两项状态都按模型分别保存，关掉 PDA 时写进配置；
  - 调整分成“头发 / 裙子与衣服 / 挂件 / 水面 / 视角 / 发光”几组，点标题展开或收起；
    滑条包括：刘海/鬓角摆动、头发刚度/重力/阻力/暗流/扭转跟随、裙子硬度、
    裙摆活动范围、裙子与腿间隙、空气重力/阻力、头部俯仰跟随、发光强度；
    “音效”组里可以开关“屏蔽主角音效”（关受伤痛呼、跳跃喘气和水下换气声，
    不关脚步/水花/气泡/PDA）；
  - 开关头发物理、裙子物理、衣服物理、挂件物理、水面物理、头发碰撞、
    第一人称显示双马尾；点“恢复默认值”还原。
    第一人称下双马尾照常显示，只有发根贴着后脑勺的一小段（约 12 cm）跟着头一起隐藏，
    避免转动视角时发根从画面边缘露出来；第三人称/第二人称仍是完整的一条马尾。
拖动立即生效。往这个文件夹里加了新模型后，在模型页点“刷新列表”重新扫描。
室内光照不用调：模型会自动读取玩家所在基地/潜艇的室内环境光。
F2 打开 MMS 控制台：总开关（关闭后恢复游戏原角色）、改菜单键位/控制台键位、
屏蔽主角音效、重建当前模型。菜单键位默认 V，控制台键位默认 F2，都能在控制台里改。
（默认值也可以在配置 [Interface] MenuKey / ConsoleKey 里改；F6 是游戏自带的 HUD 隐藏键，
F9/F12 常被截图工具占用。）
也可以在 BepInEx\config\com.miku.subnautica.playerreplacer.cfg 里
设置 [Model] ActiveModel = 子文件夹名（留空 = 用 Models 里找到的第一个模型；
同文件夹多个 pmx 时其余条目写“文件夹名/文件名”，如 sour暄/White）、
[General] Enabled = true（总开关，等于控制台里的“MMS 总开关”）、
[General] TermsAccepted / TermsDontShowAgain（使用须知窗口的答案，一般不用手改）。

支持 PMX 2.0 / 2.1；贴图支持 png / jpg / bmp / tga / dds。
贴图完全按 PMX 里记录的路径去找，和 MMD 一样：相对 PMX 所在文件夹（支持 ..\ 跳到上层），
不区分大小写，找不到同名文件时再按“同名不同扩展名”找（001.tga / 001.png）。
骨骼按标准 MMD 日文名映射（腕.L、ひじ.L、足.L ...）。名字里带
髪 / 髮 / hair / ツインテ / ponytail 的骨骼链会自动加头发物理，
ネクタイ / リボン / マフラー / Tie / ストラップ / strap 这类垂挂饰品的骨骼链也会一起摆动。

头发物理按部位分档：贴着头皮的发帽和短发层不加物理；刘海、鬓角、呆毛
（前髪 / 前髮 / もみあげ / 側髪 / 横髪 / アホ毛）整根发束当刚体，只绕发根轻轻倾斜，
不会逐关节弯曲，所以多根发丝不会卷到一起（摆动幅度 0 就是模型原样）；
长马尾、双马尾和长度 30 cm 以上的发束保持完整物理。
开物理时发束、领带等饰品会和按模型自身网格量出来的身体体积碰撞（逐骨拟合一叠
椭圆截面，跟着骨骼一起转），不会穿进身体；碰撞作用在布料表面而不是骨骼线，
领带会贴着胸口被推回。
刘海不参与身体碰撞，所以不会被头部的碰撞体顶得翘起来。
（配置在 BepInEx\config\com.miku.subnautica.playerreplacer.cfg 的 [Physics] 段。）
