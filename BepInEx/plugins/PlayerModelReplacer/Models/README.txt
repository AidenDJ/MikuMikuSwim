本模组不附带任何模型。把 MMD 模型放进这个文件夹，每个模型建一个子文件夹：

  Models\YYB Miku\
      model.pmx          <- 模型本体（只有一个 pmx 时文件名随意）
      tex\...            <- 贴图，按 PMX 里写的相对路径查找；找不到时再按文件名找

一个文件夹里可以放多个 pmx（比如同一个角色的两个配色）：

  Models\sour暄\
      Black.pmx
      White.pmx

它们会作为两个独立条目出现在模型页里，名字是「sour暄 · Black」「sour暄 · White」，
可以分别预览、分别应用。有 model.pmx 时默认选它，否则按文件名排序取第一个。

支持 PMX 2.0 / 2.1（不支持 PMD）；贴图支持 png / jpg / bmp / tga / dds。
贴图路径相对 PMX 所在文件夹（支持 ..\ 跳到上层），不区分大小写；找不到时再按
文件名和同名的其他扩展名查找（001.tga ↔ 001.png）。

第一次启动游戏（以及之后每次启动，直到勾选“不再显示”）会弹出“MMS 使用须知”：
使用任何模型前，请先阅读并遵守该模型自带的 README 中的使用条款
（署名要求、可否修改、可否商用、禁止事项等）。勾选“不再显示”再点“我同意”，
以后启动就直接进入游戏；不勾选则每次启动都会再问一次；点“我拒绝”会直接退出游戏。
没有放模型时模组不会替换任何东西，游戏照常是原版主角。

进游戏后按 V 打开 PDA 的「模型」页（也可以正常打开 PDA，点顶部标签行最后的
MMS 图标）。左边点名字先预览，确认后点“应用模型”才真正换装；右下可以按材质
隐藏/发光，调整头发、裙子与衣服、挂件、水面、视角等选项，拖动即时生效。
往这个文件夹里加了新模型后，在模型页点“刷新列表”重新扫描。

F5 循环第一人称 / 越肩第三人称 / 第二人称；小键盘 4/6 左右、8/2 上下、+/- 远近、
5 复位可以调整镜头。F2 打开 MMS 控制台（总开关、改键、重建当前模型）。
